# Nexus Captura - extensao BeeFood

1. No painel da empresa, escolha **Extensao do Chrome**, salve e gere uma chave.
2. Abra `chrome://extensions`, ligue **Modo do desenvolvedor** e use **Carregar sem compactacao** nesta pasta.
3. Abra **Configurar** na extensao e informe o WhatsApp da empresa e a chave gerada.
4. Abra um pedido no BeeFood e clique em **Capturar este pedido**.

A extensao so le a aba quando o usuario clica no botao. Como a estrutura visual do BeeFood pode mudar, o pedido sempre entra na fila de conferencia quando algum campo nao for reconhecido.
